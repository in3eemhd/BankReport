Step 1 – Create the site (one time)

  1. Go to https://<your-tenant>.sharepoint.com and sign in with your Microsoft 365 account.
  2. On the SharePoint start page click + Create site.
  3. Choose Team site, then the Standard team template.
  4. Site name: Bank Letters (or any name). Privacy settings: Private. Language: Arabic or English. Click Next.
  5. Add the colleagues who will issue bank letters as Members. Click Finish.
If you cannot see + Create site, site creation is restricted in your tenant. Ask your IT admin to create a private Team site named Bank Letters and make you an owner.

Step 2 – Upload the page

  1. Open the new site. Click the gear icon ⚙ (top right) → Site contents.
  2. Open the Site Assets library. (If it is not listed, click + New → Document library, name it Tools, and use that instead.)
  3. Click Upload → Files and choose 1-Upload-to-SharePoint/BankReport.aspx.
  4. Click the uploaded BankReport.aspx. The generator should open in the browser.
  5. Copy the address from the browser bar. It looks like
    https://<tenant>.sharepoint.com/sites/BankLetters/SiteAssets/BankReport.aspx
    This is the link you share with colleagues.

Step 3 – If the page does not open (blank page, "blocked", or it downloads)

This means custom scripts are disabled for the site, which is Microsoft's default. A SharePoint administrator fixes it in one of two ways:

Option A – from the web (SharePoint admin center)

  1. Go to https://<tenant>-admin.sharepoint.com → Sites → Active sites.
  2. Select the Bank Letters site → Settings tab (in the side panel).
  3. Under Custom scripts choose Allow → Save. Wait a few minutes and open the page again.

Option B – PowerShell (run 3-Admin-if-page-is-blocked/Enable-CustomScript.ps1 after replacing <tenant> and <site>):

Connect-SPOService -Url https://<tenant>-admin.sharepoint.com
Set-SPOSite -Identity https://<tenant>.sharepoint.com/sites/BankLetters -DenyAddAndCustomizePages $false
On some tenants Microsoft re-blocks custom scripts automatically after 24 hours. If the page stops working later, repeat this step, or use the alternative below.

Alternative without custom scripts: host 2-Backup-standalone/BankReport.html on any company HTTPS web server (IIS, Azure Static Web App, etc.), then on a SharePoint page add the Embed web part and paste that address. If SharePoint refuses the address, a site owner adds the server's domain under ⚙ → Site information → View all site settings → HTML Field Security.

Step 4 – Make it easy to find

  1. On the site home page click Edit (top right).
  2. Click + in a section → Quick links (or Button) → paste the page link from Step 2 → title it Bank Letter Generator.
  3. Click Republish.
  4. Optional: in the left navigation click Edit → + Add link → paste the same link.

Step 5 – Daily use

  1. Open the page.
  2. Choose the financing type: تمويل إسلامي – تسهيلات رواتب or تمويل فواتير. The subject, facility name and repayment period change to that type's defaults; all remain editable.
  3. Enter the amount. The Arabic words appear automatically (فقط … لا غير).
  4. Set the repayment period, the bank account (two fixed choices), the date and the reference number.
  5. Click تنزيل ملف Word. The letter downloads as a .docx on the letterhead in Sakkal Majalla. Open it in Word to sign and print.
  6. Save the Word file in the site's Documents library so the letters are kept with the tool.

The fields are remembered in your browser, so the next letter starts from the previous values. إعادة تعيين الكل clears them (press twice to confirm).

Step 6 – Updating the page later

  1. Get the new BankReport.aspx.
  2. In Site Assets click Upload → Files, choose it, and confirm Replace when asked.
  3. Users press Ctrl+F5 once to reload.

Notes

  • The letter uses the Sakkal Majalla font, which ships with Windows and Microsoft 365. On a device without it, the page and Word substitute a fallback font; the file still keeps Sakkal Majalla and shows it on a company PC.
  • Company name, commercial registration number and the bank are fixed inside the page and cannot be changed from the form. To change them, ask for a new BankReport.aspx.
  • The page stores nothing on the server. Each user's last values stay in their own browser only.

ملخص بالعربية

  1. أنشئ موقع فريق (Team site) خاصاً باسم «Bank Letters» من صفحة SharePoint الرئيسية عبر + Create site، وأضف الزملاء أعضاءً.
  2. من ⚙ → Site contents → Site Assets ارفع الملف BankReport.aspx ثم افتحه. رابطه هو الذي تشاركه مع الزملاء.
  3. إذا ظهرت صفحة فارغة أو محظورة، يفعّل مسؤول SharePoint خيار Custom scripts → Allow من مركز الإدارة (Active sites → الموقع → Settings)، أو يشغّل ملف PowerShell المرفق.
  4. أضف رابط الصفحة إلى الصفحة الرئيسية للموقع عبر Edit → Quick links.
  5. الاستخدام اليومي: اختر نوع التمويل، أدخل المبلغ والمدة والحساب والتاريخ ورقم الصادر، ثم تنزيل ملف Word، واحفظ الخطاب في مكتبة Documents.
  6. لتحديث الصفحة لاحقاً ارفع ملف BankReport.aspx الجديد مكان القديم.
